# ☕ Exercícios Práticos de Java & Programação Orientada a Objetos (POO)
Repositório dedicado à consolidação e prática dos pilares da **Programação Orientada a Objetos (POO)** e lógica em **Java**. Todos os códigos foram desenvolvidos de forma autônoma para aplicar conceitos fundamentais na prática.
---
## 🎯 Conceitos Praticados
- **Abstração:** Modelagem de entidades do mundo real em classes Java coesas.
- **Encapsulamento:** Proteção de dados e estado com modificadores de acesso (`private`, `protected`, `public`) e métodos `getters`/`setters`.
- **Herança:** Reutilização e extensão de código através de classes base e derivadas (`extends`).
- **Polimorfismo:** Sobrescrita (`@Override`) e sobrecarga de métodos para comportamentos dinâmicos.
- **Associação e Agregação:** Relações entre objetos (um-para-um, um-para-muitos).
